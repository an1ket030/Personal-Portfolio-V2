# Personal-Portfolio-V2

A vintage Game Boy-themed creative portfolio built with modern web technologies. Features an interactive boot sequence, pixelated canvas backgrounds, chiptune sound effects, and retro gaming aesthetics blended with premium UI design.

## Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Animation:** GSAP + ScrollTrigger
- **Sound:** Web Audio API (chiptune synthesis)
- **Styling:** CSS Modules
- **Icons:** Lucide React

## Features

- 🎮 **Boot Sequence** — Animated Game Boy startup with chiptune melody
- 🌟 **Hero Section** — Pixelated canvas world with floating clouds, coins, and question blocks
- 🏆 **Project Showcase** — Interactive project cards with hover effects
- ⚔️ **Skills** — RPG-style stat bars and ability grid
- 👤 **About** — Player select card with timeline and marquee hobbies
- 📬 **Contact** — Game Over-themed form with social links
- 🔊 **Sound System** — Click SFX, scroll chimes, and boot music
- 🥚 **Easter Eggs** — Try the Konami Code! ↑↑↓↓←→←→BA
- 📺 **CRT Overlay** — Subtle scanlines and vignette for retro feel

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
